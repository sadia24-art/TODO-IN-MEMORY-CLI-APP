## Prompt

```text
/sp.specify

Project: In-Memory Python Console Todo Application (Phase I)

Objective:
Specify the requirements for building a basic-level, in-memory, command-line Todo application using a fully spec-driven, agentic development workflow.

Target Environment:
- Local console (CLI-based)
- In-memory execution only (no persistence)

Target Audience:
- AI agents (Claude Code) implementing features via Spec-Kit Plus
- Evaluators reviewing spec quality, prompts, and agentic workflow

Scope:
The system must support a minimal but complete Todo workflow using in-memory data structures.

Core Features (Must Implement All):
1. Add a todo item
2. Delete a todo item
3. Update a todo item
4. View all todo items
5. Mark a todo item as complete

Development Approach:
- Follow Agentic Dev Stack workflow strictly:
  Spec → Plan → Tasks → Implementation
- No manual coding by humans
- All implementation must be generated by Claude Code
- Use Spec-Kit Plus conventions throughout

Technical Requirements:
- Language: Python 3.13+
- Environment & tooling: UV
- Console-based input/output only
- In-memory data storage (lists, dicts, or equivalent)
- Clean, modular Python project structure
- Readable, maintainable code following clean code principles

Quality Standards:
- Clear separation of concerns (CLI, logic, data handling)
- Deterministic behavior for all commands
- Meaningful function and variable naming
- Graceful handling of invalid user input

Success Criteria:
- All 5 core features work correctly in a single runtime session
- No persistence layer is used
- Application runs from the console without errors
- Specs can be traced directly to plans, tasks, and implementation
- Evaluators can clearly see spec-driven development in action

Constraints:
- No database or file storage
- No GUI or web interface
- No authentication or user accounts
- No advanced features (priorities, deadlines, reminders)

Not Building:
- Persistent storage (files, SQLite, cloud DBs)
- Web or API-based interfaces
- AI-powered features (reserved for later phases)
```
